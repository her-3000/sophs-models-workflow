# Workflow and evidence boundaries

1. Read the current locally authorized scope and rule decision. Reconcile the saved phase and receipts before action. A queued task is not proof of execution.
2. Admit only one desktop owner atomically. Preserve another owner's active lease and release only the matching owned run. No unlock or login bypass.
3. Discover and extract original casting briefs within the actual remaining budget. Save partial coverage and historical gaps honestly. Missing material, unclear eligibility or an exclusive unverified route is a hold.
4. Review the exact proposed outreach separately. External review waiting does not consume screening time. An action budget starts only after a specific allowed decision and fresh open-status, route, eligibility, assets and dedupe checks. Unknown transmission outcomes are never blindly replayed.
5. Record terminal scope, known outcomes and postflight before release. Submitted, admin-pending, known-unsent and uncertain are distinct states. Never infer a booking or human reading from submission/delivery evidence.
6. Deliver one bounded internal update. When a business API failure is known-unsent or verified allowance insufficient, a separately authorized native route may be used only after verifying account, established group members/history, current human messages and current rule decision. An uncertain API outcome must be reconciled first. Full outgoing readback is stronger than an API acceptance but still does not establish human reading.
7. A single daily read-only quota check is claimed per local calendar day inside the existing workflow. Preserve raw observed values and errors; unknown reset time stays unknown. No send probes, paid upgrades or new timer are implied.
8. The final daily summary states outcomes, required materials/decisions and next steps with original source links and actual deadlines, separating submitted and unsent work. Failed older digests may be additively consolidated into one current summary, never rewritten as individually delivered or replayed as a burst.
9. Explicitly release the owned lease after saving a reconciled terminal checkpoint. Preserve the next normal reservation; an exceptional manual invocation creates no recurring overnight authority.

These are deidentified operating principles, not copies of private custom rules or a live automation prompt. Personal contact details, asset packs, client briefs, raw receipts, private quota/account records, machine paths and real runtime identifiers are intentionally excluded.
